# Threat Model - TorChat V2

## Overview
This document describes the threat model for TorChat V2.

## Attackers
- Attacker A: Network Observer
- Attacker B: Malicious Peer
- Attacker C: Compromised Peer
- Attacker D: Stolen Device
- Attacker E: Stolen Encrypted Storage
- Attacker F: Rooted Device
- Attacker G: Compromised OS
